PROJECT N.O.V.A. is a cinematic Windows desktop voice assistant focused on fast desktop control, privacy-conscious design, and an immersive operator-style interface.

Key Features

Voice-driven desktop control for launching apps, managing windows, handling media, and running common system actions
Multi-turn conversation flow with wake phrase support and spoken responses
Weather, calendar, and desktop utility integrations
Real-time dashboard UI with transcripts, diagnostics, media status, and system panels
Local-first configuration and memory files stored on the user’s PC

Privacy

Built with a local-first desktop architecture
User setup, preferences, and runtime memory are stored locally on the machine
Third-party services are only used for features that require them, such as AI responses, weather, or calendar connectivity
Designed to keep user control and transparency first
